# Bài Tập: Tạo Form Đăng Ký Người Dùng (User Registration Form)

Bài tập thực hành tạo biểu mẫu đăng ký người dùng với phương thức POST:
- Thẻ `<form action="http://demo.codegym.vn/6/registration_form/register.php" method="POST">`.
- Trường Họ và tên: `<input type="text" name="name">`.
- Trường Email: `<input type="email" name="email">`.
- Trường Số điện thoại: `<input type="tel" name="phone">`.
- Trường Giới tính: radio button với `name="gender"` (Nam, Nữ, Khác).
- Nút submit Đăng ký.

## 🚀 Cách mở xem
Mở trực tiếp tệp [`index.html`](index.html) bằng trình duyệt web bất kỳ (Chrome, Edge, Firefox,...).
